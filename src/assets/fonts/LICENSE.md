# Polices embarquées (images de partage Open Graph)

Ces fichiers `.woff` servent uniquement au rendu côté serveur des images de
partage (`opengraph-image.tsx`), car le moteur utilisé (Satori) ne lit pas le
format WOFF2 fourni par les paquets fontsource utilisés dans les pages.
